# Perfboard Designer

2.54 mm ピッチのユニバーサル基板へ部品と配線を配置し、表面・裏面の組み立て図と接続状態を確認するためのデスクトップアプリのソースコードです。

## ポートフォリオとしての要点

- React、TypeScript、Vite と Tauri 2 を用いたデスクトップ設計ツール
- SVGベースの基板描画、穴単位の部品配置、表面／裏面配線
- ネット割り当てと接続検査、Undo/Redo、JSON設計ファイル、SVG組み立て図出力
- 基板設計のドメイン処理をUIから分離し、座標変換・部品回転・接続解析を単体テストで検証

## 公開範囲

このリポジトリは、ポートフォリオ用に許可されたソースコード、ビルド設定、ライセンス、操作マニュアルだけを公開するスナップショットです。実行ファイル、ビルド成果物、設計データ、スクリーンショット、秘密情報、内部資料は含めません。

操作方法は [日本語操作マニュアル](docs/USER_MANUAL.md) を参照してください。マニュアル内の画面キャプチャは、公開対象をソースコードと文書に限定するため、このスナップショットには含めていません。

## 主な技術

- Tauri 2 / Rust
