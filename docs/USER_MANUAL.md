# Perfboard Designer 操作マニュアル

Perfboard Designer は、2.54 mm ピッチのユニバーサル基板に部品と配線を配置し、表面・裏面の組み立て図と接続状態を確認するためのデスクトップアプリです。

このマニュアルは、アプリに実装されている操作を対象にしています。設計座標はすべて「列・行」の整数で扱われ、画面の拡大率や裏面の左右反転を変えても、保存される配置座標は変わりません。

## はじめに

### 対象とする基板

- 穴ピッチは固定で **2.54 mm** です。
- 新規設計の基板サイズは **30列 × 20行** です。
- 列・行は画面上では **1番から** 表示されます。保存データ内部では 0 番からの整数です。
- 基板の物理的な穴中心間寸法は、`(列数 - 1) × 2.54 mm` と `(行数 - 1) × 2.54 mm` です。

### 最初の設計を作る

1. アプリを起動します。空の 30列 × 20行基板が表示されます。
2. 必要なら「基板と配置」を開き、列数・行数を入力して「基板サイズを反映」を選びます。
3. 「部品パレット」から部品を選び、基板上の穴をクリックして配置します。
4. 「編集ツール」で配線の種類を選び、始点と終点の穴を順にクリックします。
5. 「ネット」タブで信号名を作り、部品タブから各端子に割り当てます。
6. 「接続検査」タブで問題がないか確認します。
7. 「保存」を選び、`.perfboard.json` ファイルとして保存します。
8. 組み立て用に「組み立て図の出力」から表面・裏面 SVG を出力します。

## 画面の見方

![部品と両面配線を配置した編集画面](images/editor-board.png)

画面は主に次の領域で構成されます。

| 領域     | 用途                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| 上部     | 設計名、未保存状態、基板サイズ、部品・配線・ネットの件数を表示します。                               |
| 左側上部 | 設計ファイル、Undo/Redo、編集ツール、表示面を操作します。                                            |
| 左側下部 | 部品パレット、基板設定、配置全体の移動、SVG出力、表示倍率をまとめています。折りたたみ可能です。      |
| 右側     | 「部品」「配線」「ネット」「接続検査」のタブです。選択中の対象を編集・確認します。                   |
| 中央     | SVG で描画される基板です。穴をクリックして配置・配線し、選択ツールでは部品や配線をドラッグできます。 |

「未保存」と表示されている間は、最後に保存したファイルに反映されていない変更があります。

## 基本的な作業の流れ

### 1. 基板を設定する

「基板と配置」→「基板設定」で列数と行数を変更します。どちらも 1 以上の整数です。既に置いた部品または配線が基板外へ出るサイズには変更できません。

### 2. 表示面を決める

「表示面」で次を選びます。

| 表示       | 内容                           |
| ---------- | ------------------------------ |
| 表面       | 部品面を主表示します。         |
| 裏面       | はんだ面を主表示します。       |
| 重ね合わせ | 表面・裏面を重ねて確認します。 |

「裏面を左右反転して表示」を有効にすると、基板を裏側から見た状態に合わせて左右を反転します。部品・配線の保存位置は変わりません。「部品ラベルを表示」は基板上の部品番号・値の表示と、SVG出力に含めるラベルを切り替えます。

### 3. 部品、配線、ネットを作る

部品を置き、必要な配線を作成してから、ネットを作成・割り当てる順序が分かりやすい方法です。ネットは先に作っても構いません。接続検査は編集に合わせて自動更新されます。

## 基板と表示の操作

### 表示倍率と表示位置

「表示の詳細」には、倍率、表示範囲の移動、表示リセットがあります。

- **縮小 / 拡大**: 10%ずつ倍率を変更します。
- **トラックパッド・マウスホイール**: `⌘` または `Ctrl` を押しながらスクロールすると拡大・縮小します。
- **表示範囲の矢印**: 表示位置を一定量ずつ移動します。
- **パン操作**: 基板上で中クリック、または `Shift` を押しながら左ドラッグします。
- **表示をリセット**: 倍率、表示位置、表示面、裏面反転、部品ラベル表示を初期状態へ戻します。設計データは変更しません。

### 配置全体を移動する

「基板と配置」→「配置全体を移動」の矢印を選ぶと、すべての部品と配線を一緒に 1 穴ずつ移動します。基板外へ出る移動は受け付けません。部品の配置中または配線の作成中は使用できません。

## 部品の配置と編集

### 配置する

1. 「部品パレット」で部品を選びます。
2. カーソルを基板へ動かし、プレビューが基板内に収まる穴を探します。
3. 穴をクリックして配置します。
4. 続けて同じ部品を配置することもできます。終了するには「配置を中止」または `Esc` を選びます。

基板外にはみ出す位置は確定できません。部品の端子が占める穴を基準に判定されるため、回転後の大きさにも注意してください。

### 対応部品と初期設定

| 部品         | 端子・初期設定                 | 変更できる設定                                                                    |
| ------------ | ------------------------------ | --------------------------------------------------------------------------------- |
| 抵抗         | 2端子、端子間に3穴、初期値 1kΩ | 部品番号、値・表示名、回転                                                        |
| LED          | A（アノード）/ K（カソード）   | 部品番号、値・表示名、発光色（赤・緑・青・黄・オレンジ・白）、回転                |
| ダイオード   | A / K、カソード帯を表示        | 部品番号、値・表示名、回転                                                        |
| コンデンサ   | + / - の2端子                  | 部品番号、値・表示名、極性あり／無極性、回転                                      |
| DIP IC       | 初期値 DIP-8                   | 部品番号、値・表示名、端子数（8、14、16、18、20、24、28、40）、回転               |
| ピンヘッダー | 初期値 1列・4端子・オス        | 部品番号、値・表示名、オス／メス、1列／2列、端子番号の向き、端子数（1〜20）、回転 |
| 汎用コネクタ | 初期値 1列・2端子              | 部品番号、値・表示名、端子数（1〜20）、回転                                       |
| タクトSW     | 6 × 6 mm、4端子                | 部品番号、値・表示名、回転                                                        |

2列ピンヘッダーは偶数端子数だけ指定できます。設定変更により端子が基板外へ出る場合、変更は拒否されます。

### 選択・移動・設定変更・削除

「選択」ツールに切り替えてから操作します。

- **選択**: 部品をクリックします。右側が自動で「部品」タブになります。
- **移動**: 部品を左ドラッグします。穴単位で移動し、基板外へは移動できません。
- **設定**: 右側の「部品」タブで部品番号と値・表示名を入力し、「設定を反映」を選びます。部品種別ごとの設定もここで変更します。
- **回転**: 「90度回転」または `R` を選びます。回転は 90 度ずつです。
- **削除**: 「削除」または `Delete` / `Backspace` を選びます。部品に割り当てたネットも同時に解除されます。
- **選択解除**: 基板の空白部分をクリックします。

部品番号は設計内で重複できません。重複した場合はエラーが表示され、既存の配置は保持されます。

### タクトSWの扱い

タクトSWは 2.54 mm 格子向けの模式フットプリントです。上側の `A1 / A2` と下側の `B1 / B2` は、それぞれ別の導通グループです。ネットの割り当ては4端子を個別ではなく、上側・下側のグループごとに行います。

## 配線の作成と編集

### 配線の種類

「編集ツール」では、次の3種類を選べます。

| ツール           | 用途                     | 面       |
| ---------------- | ------------------------ | -------- |
| 表面ジャンパー線 | 部品面側のジャンパー線   | 表面     |
| 裏面はんだ配線   | はんだ面側の配線         | 裏面固定 |
| 裏面ジャンパー線 | 裏面側で使うジャンパー線 | 裏面     |

### 配線を作成する

1. いずれかの配線ツールを選びます。
2. 基板上の始点の穴をクリックします。
3. 終点の穴をクリックします。
4. 直線配線が作成されます。

始点と終点は必ず基板内の穴へ吸着します。同じ穴を始点・終点にすることはできません。作成中は終点候補がプレビュー表示され、「配線作成を中止」または `Esc` で取り消せます。

### 配線を編集する

1. 「選択」ツールを選びます。
2. 配線をクリックすると右側が「配線」タブに切り替わります。
3. 必要に応じて次を変更します。

| 項目       | 内容                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| 配線種類   | ジャンパー線／はんだ配線を切り替えます。はんだ配線にすると裏面になります。 |
| 配線面     | ジャンパー線の表面／裏面を切り替えます。はんだ配線は裏面固定です。         |
| 表示色     | 青、赤、緑、黄、オレンジ、紫、黒から選びます。                             |
| 始点・終点 | 現在の穴位置を表示します。端点をドラッグして移動できます。                 |

配線そのものを左ドラッグすると、両端を保ったまま移動します。端点のハンドルをドラッグすると、片方だけを別の穴へ移動できます。基板外、または長さ0の配線になる編集は確定できません。「配線を削除」または `Delete` / `Backspace` で削除します。

## ネットと接続検査

ネットは `3V3`、`GND`、`SPI_MOSI` のような電気的に同じ接続先を示す名前です。ネットは配線そのものに直接付けるのではなく、部品端子へ割り当てます。配線と部品内部の導通グループから、アプリが接続状態を計算します。

![ネット一覧と基板上の強調表示](images/network-management.png)

### ネットを作成・編集する

1. 右側の「ネット」タブを開きます。
2. 「ネットを作成」でネット名、種類、色を指定し、「ネットを追加」を選びます。
3. 一覧のネットを選択すると、基板上の関連箇所が強調表示されます。同じネットをもう一度選ぶと強調を解除します。
4. 選択後に表示される編集欄で名称、種類、色を変更できます。

ネット種類は **信号**、**電源**、**GND** です。ネット名は空欄にできず、大文字・小文字を区別せずに重複できません。

ネットを削除すると、確認画面が表示されます。削除を確定すると、関連するすべての端子割り当ても同時に削除されます。

### 部品端子へネットを割り当てる

1. 基板上の部品を選び、「部品」タブを開きます。
2. 「端子のネット割り当て」で、各端子のネットを選びます。
3. 不要になった割り当ては「割り当て解除」、または選択欄の「未割り当て」を選びます。

タクトSWでは、「上側（A1 / A2）」と「下側（B1 / B2）」へネットを割り当てます。

### 接続検査を使う

![ネットと接続検査を表示した画面](images/connectivity-inspection.png)

「接続検査」タブは編集内容に合わせて自動更新されます。問題カードを選ぶと、関連する穴、端子、部品、配線を基板上で強調表示します。「強調を解除」で通常表示に戻せます。ネットを選択中なら、そのネットに関係する問題だけを絞り込みます。

検出する問題は次のとおりです。

| 重要度 | 問題                                             | 意味                                                       |
| ------ | ------------------------------------------------ | ---------------------------------------------------------- |
| 重大   | 電源とGNDが接続されています                      | 電源種類とGND種類のネットが同じ接続グループにあります。    |
| エラー | 異なるネット同士が接続されています               | 同一グループの端子に異なるネットが割り当てられています。   |
| 警告   | 同じネットが複数の接続グループに分断されています | 同名ネットの端子が、配線などでつながっていません。         |
| 警告   | ネット割り当て済みの端子が接続されていません     | 割り当てた端子が、他の端子または配線につながっていません。 |

検査カードには、ネット名、部品端子、基板穴、関係する配線ID、接続グループIDが表示されます。これを基に配線または端子の割り当てを修正してください。

### 接続検査の解釈

接続検査は回路シミュレーションではありません。

- 配線は **始点と終点の穴だけ** を接続します。
- 画面上で直線配線が交差しても、接続とはみなしません。
- 配線の途中を通過する穴も、接続とはみなしません。
- 抵抗は両端子が内部で導通しているものとして扱います。
- タクトSWは上側の2端子と下側の2端子をそれぞれ導通として扱います。
- LED、ダイオード、コンデンサ、DIP IC、ピンヘッダー、汎用コネクタの内部回路は解析しません。

## 保存・読込・復旧

### 保存する

- **保存**: すでに保存先がある場合は、そのファイルへ上書きします。初回はOS標準の保存ダイアログが開きます。
- **別名保存**: 常に保存先を選びます。
- 推奨拡張子は **`.perfboard.json`** です。拡張子を省略しても自動で付きます。
- 「設計名とファイル情報」を開くと、設計名、現在のファイル名、保存状態を確認・変更できます。設計名を変えたら「反映」を選びます。

保存に失敗した場合も、編集中の設計は失われません。画面に日本語のエラーが表示されるため、保存先やアクセス権を確認してもう一度保存してください。

### 新規作成・ファイルを開く

- **新規**: 空の初期基板を作ります。
- **開く**: OS標準のファイル選択ダイアログから設計ファイルを読み込みます。

未保存の変更があると、新規作成・読込・アプリ終了の前に確認画面が表示されます。

| 選択       | 動作                                       |
| ---------- | ------------------------------------------ |
| 保存       | 保存に成功した後、続きの操作を実行します。 |
| 保存しない | 現在の未保存変更を破棄して続行します。     |
| キャンセル | 現在の設計をそのまま維持します。           |

読み込むファイルは、内容と形式を検証してから現在の設計へ反映します。不正なJSON、未対応バージョン、基板外の座標、重複する部品番号などを含むファイルは開かれず、現在編集中の設計は維持されます。

### 自動保存から復旧する

デスクトップアプリでは、未保存の変更を約1.5秒後に復旧用データとして自動保存します。通常保存とは別の場所に保存され、設計ファイルを勝手に上書きすることはありません。

前回の未保存データがある状態で起動すると、「復旧できる設計があります」と表示されます。

- **復元する**: 未保存データを編集画面へ戻します。元の設計ファイルには書き込まれないため、復元後は保存先を選んで保存してください。
- **破棄する**: 復旧データを削除し、新規設計で開始します。

正常に保存した後、または新規作成・別ファイル読込を行った後は、不要な復旧データを削除します。

## 組み立て図（SVG）の出力

「組み立て図の出力」から次を出力できます。

- **表面SVGを出力**: 部品面、表面ジャンパー線、部品外形・端子を出力します。
- **裏面SVGを出力**: はんだ面、裏面配線、部品端子位置のガイドを出力します。

出力ファイル名は、設計名を基に `設計名-front.svg`、`設計名-back-mirrored.svg`、または `設計名-back-unmirrored.svg` のように提案されます。保存先はOS標準のダイアログで選びます。

出力には、列1側の向きマーク、行・列番号、部品端子、10 mm確認スケール、印刷時の注意を含みます。編集中だけに表示される選択枠や接続検査の強調表示は出力されません。ピンヘッダーはオス／メスが分かる外形で出力されます。

### 実寸で印刷する手順

1. 出力したSVGをSVG対応アプリまたはブラウザで開きます。
2. 印刷設定で **「100%」または「拡大縮小なし」** を選びます。
3. 「用紙に合わせる」は選ばないでください。
4. 出力内の **確認用 10mm** スケールを実測し、10 mmであることを確認します。

裏面SVGの左右反転は、出力時の「裏面を左右反転して表示」の状態を反映します。基板を裏から見て作業するなら、通常は左右反転ありを使用します。

## キーボードショートカット

入力欄を編集している間は、誤操作を避けるためショートカットは機能しません。

| キー                        | 操作                                     |
| --------------------------- | ---------------------------------------- |
| `V`                         | 選択ツール                               |
| `F`                         | 表面ジャンパー線ツール                   |
| `B`                         | 裏面はんだ配線ツール                     |
| `J`                         | 裏面ジャンパー線ツール                   |
| `R`                         | 選択中の部品を90度回転                   |
| `Delete` / `Backspace`      | 選択中の部品または配線を削除             |
| `Esc`                       | 部品配置、配線作成など進行中の操作を中止 |
| `⌘Z` / `Ctrl+Z`             | 元に戻す                                 |
| `⌘Shift+Z` / `Ctrl+Shift+Z` | やり直す                                 |

## 元に戻す・やり直す

「操作履歴」の「元に戻す」「やり直す」、またはショートカットを使います。履歴は最大100件です。部品・配線・基板・ネット・端子割り当て・設計名などの設計変更が対象です。

ドラッグによる移動は、開始から終了までを1件の操作として扱います。元に戻した後に新しい編集を行うと、それまでのやり直し履歴は消えます。表示倍率・表示位置・表示面の切り替えは設計変更ではないため、Undo/Redoの対象外です。

## 保存ファイルの仕様

保存ファイルは整形済みJSONです。現在のアプリは `formatVersion: 0` を使用します。外部から編集したファイルを開く場合は、次の点に注意してください。

- `application` は `perfboard-designer` である必要があります。
- `formatVersion` は `0` である必要があります。
- `board.pitchMm` は `2.54` 固定です。
- 座標は整数で、すべて基板内でなければなりません。
- 部品ID・配線IDは共通して一意、部品番号とネット名も重複不可です。
- 配線は現時点では始点・終点の2点からなる直線です。

空の設計ファイルの例です。

```json
{
  "formatVersion": 0,
  "application": "perfboard-designer",
  "metadata": {
    "name": "名称未設定"
  },
  "board": {
    "columns": 30,
    "rows": 20,
    "pitchMm": 2.54
  },
  "components": [],
  "wires": [],
  "nets": [],
  "pinNetAssignments": []
}
```

通常はJSONを直接編集せず、アプリで変更・保存してください。検証に失敗したファイルは読み込まれませんが、現在の編集内容は保護されます。

## 制限事項と注意点

- 配線は直線1本です。折れ線配線、途中点の追加、はんだブリッジ専用ツール、自動配線はありません。
- SVG出力には対応していますが、PNG出力には対応していません。
- 接続検査は配線と一部部品の導通を確認する補助機能であり、回路の動作や定格を検証するシミュレータではありません。
- 回路図編集、SPICEシミュレーション、ガーバー出力、KiCad連携、クラウド保存、共同編集には対応していません。
- macOSを最初の確認対象としています。Windows向け構成はありますが、動作および配布は未検証です。

## 困ったときは

| 状況                       | 確認すること                                                                                  |
| -------------------------- | --------------------------------------------------------------------------------------------- |
| 部品を置けない             | プレビューが基板内に収まっているか、配置中の操作を `Esc` で一度中止していないかを確認します。 |
| 配線を作れない             | 始点・終点が別の基板穴か、両方が基板内かを確認します。                                        |
| 部品設定を変えられない     | 端子数や回転によって基板外へ出ないか確認します。2列ピンヘッダーは偶数端子数です。             |
| 基板サイズを小さくできない | 既存部品または配線が新しい範囲外へ出るためです。先に配置を移動・削除します。                  |
| ネットが赤字エラーになる   | ネット名の空欄・重複、または部品番号の重複を確認します。                                      |
| 接続検査で警告が出る       | 問題カードを選択し、強調された穴・端子・配線を確認して配線または端子割り当てを修正します。    |
| 保存・読込に失敗する       | 画面の日本語エラーを確認します。読込失敗時も現在の設計は維持されます。                        |
| 実寸印刷にならない         | 印刷設定を100%にし、SVGの10 mmスケールを実測します。                                          |
